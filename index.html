Le module

Comprendre avant de construire, prouver avant de croire.

Les modèles de langage rédigent avec aisance, y compris quand ils se trompent. Ce module donne aux professionnels de santé les repères pour concevoir un assistant utile, et surtout pour vérifier chacune de ses réponses.

01
🧠

Comprendre

Ce que fait un LLM, pourquoi il hallucine, comment une consigne, des sources et des outils changent son comportement.

02
🛠️

Construire

Un agent dans Dify Cloud, sans code : instructions, base documentaire, outil annuaire et publication d’un prototype.

03
🔍

Vérifier

Lire la trace, tester les cas d’absence et les limites, provoquer une panne, puis réparer et rejouer la grille de tests.

Public

Médecins, spécialistes, cadres et personnel administratif hospitalier.

Prérequis

Aucune compétence en programmation. Un ordinateur et un compte Dify Cloud.

Format

Une séance de présentation, puis une journée ou deux demi-journées d’atelier.

Groupe

Dix apprenants, un prototype personnel par participant.

Les deux supports

Une présentation pour comprendre, un atelier pour faire.

Les deux pages fonctionnent dans le navigateur, sans compte et sans connexion à une IA. Elles partagent le même fil conducteur : Horizon Assistant, un agent administratif sur des documents entièrement fictifs.

Le fil rouge

Où se trouve le bureau des admissions ?

Deux réponses produites par un assistant. Toutes deux citent une source. Laquelle croiriez-vous ?

La bonne réponse est B. Mais le plus intéressant est ailleurs : pourquoi l’assistant a-t-il produit A, avec une référence qui semblait si crédible ? L’enquête se mène dans la présentation, et chaque participant reproduit la panne dans l’atelier.

Nos engagements

Un cadre sûr pour apprendre.

🧪Données fictives

Établissement, procédures et annuaire sont inventés. Aucune donnée patient.

🩺Aucune décision clinique

L’agent prépare et oriente ; le professionnel décide.

🧾Preuve observable

Une réponse se vérifie dans la source et dans la trace, jamais sur parole.

🔒Lecture seule

Aucun outil d’envoi, de réservation ou de modification de dossier n’est connecté.

Le cadre éthique et réglementaire des données de santé est traité dans un module dédié de ce cours.
